# Mayordommo logo — P2, LOCKED 2026-10-02

- Wordmark: lowercase `mayordommo` set in Marcellus 400 (locked 2026-10-04, replacing Cormorant Garamond 700; body/UI face is Manrope). Leave clear space under the logo so the faded reflection ends before the letters begin.
