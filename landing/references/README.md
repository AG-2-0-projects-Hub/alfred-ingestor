# Landing references

One file per reference, named after the site, for example `kombai-<name>.md` or `glass-<name>.md`. Paste the Kombai/Refero `design.md` as it is, and put these three lines at the very top:

- **URL:** the live page (so motion can be measured, a design.md cannot capture it)
- **Take:** what we borrow (layout, composition, motion, glass recipe)
- **Ignore:** anything we do not borrow (colours and fonts are locked: Aubergine/Bone/Gold palette, Marcellus + Manrope)

Screenshots or a short screen recording of the moment you like go in the same folder, same name prefix.
